HybrIK-X: Hybrid Analytical-Neural Inverse Kinematics for Whole-body Mesh Recovery

Jiefeng Li, Siyuan Bian, Chao Xu, Zhicun Chen, Lixin Yang, Cewu Lu
Skeleton-to-SMPLX SMPLX Inverse Kinematics Whole-body Mesh Hybrid Analytical + Neural arXiv 2023
arXiv PDF
One-sentence problem: Standard mesh-parameter regression can produce misaligned image-mesh fitting, while direct 3D keypoint estimation may violate body structure - can inverse kinematics bridge accurate joints and realistic SMPL-X rotations in one stage?
一句话问题：直接回归 mesh 参数易出现图像与网格错位，直接 3D 关键点估计又可能不满足人体结构约束——能否通过逆运动学在单阶段中同时获得关键点精度与 SMPL-X 结构合理性？

Key Idea

  • Hybrid IK decomposition: HybrIK-X decomposes joint rotation into swing and twist. Swing is solved analytically from 3D joints, while twist is predicted by neural features from image evidence.
    混合 IK 分解：将关节旋转分解为 swing 和 twist。swing 由 3D 关节点解析求解，twist 由网络从图像特征中预测。
  • Whole-body extension: Compared with original HybrIK, HybrIK-X extends the framework to expressive whole-body modeling with hands and face using SMPL-X.
    全身扩展：相较原始 HybrIK，HybrIK-X 将框架扩展到带手和面部的 SMPL-X 全身表达建模。
  • One-stage pipeline: The method targets fast end-to-end whole-body mesh recovery while preserving structural plausibility from IK constraints.
    单阶段流程：方法面向端到端快速全身网格恢复，同时借助 IK 约束保持结构合理性。

Method Sketch

Stage 1 Input RGB image → Backbone predicts 3D joints + latent cues
Stage 2 (Hybrid IK) Analytical solver → Swing rotation from joints + Neural head → Twist rotation from visual cues
Stage 3 Swing + Twist + Shape params → SMPL-X whole-body mesh (body + hands + face)

  • Bridging role: This line of work complements pure regression methods by injecting explicit IK structure, useful as a strong baseline for future SMPL-X pipelines.

TL;DR

HybrIK-X formulates whole-body SMPL-X recovery as a hybrid inverse kinematics problem: solve swing analytically from 3D joints and learn twist from image cues. This keeps skeleton alignment accuracy while producing more plausible parametric whole-body meshes, making it a representative paper for the new Skeleton-to-SMPLX tag.
