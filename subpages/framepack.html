Frame Context Packing and Drift Prevention in Next-Frame-Prediction Video Diffusion Models

Lvmin Zhang, Shengqu Cai, Muyang Li, Gordon Wetzstein, Maneesh Agrawala
Others Video Diffusion FramePack Drift Prevention arXiv 2025
arXiv PDF Code
One-sentence problem: How can next-frame video diffusion models keep very long temporal context and avoid autoregressive drift/error accumulation, without exploding context length or sacrificing training throughput?
一句话问题：next-frame 视频扩散模型如何在不让上下文长度爆炸、又不牺牲训练吞吐的前提下，保留超长时序信息并抑制自回归漂移与误差累积？

Key Contributions

  • FramePack context compression: allocates variable context budget per frame based on importance, enabling significantly longer effective history under fixed token limits.
    FramePack 上下文压缩：按帧重要性分配可变上下文预算，在固定 token 上限下保留更长有效历史。
  • Multiple packing schedules: supports time-proximity, feature-similarity, and hybrid importance metrics, so models can bias context toward temporally recent frames or semantically relevant frames.
    多种打包策略：支持时间邻近、特征相似度和混合重要性度量，使模型可偏向最近帧或语义相关帧。
  • Anti-drift design suite: combines endpoint anchoring, sampling-order adjustment, and discrete history representation to reduce observation bias in long-horizon autoregressive rollout.
    防漂移机制组合：通过端点锚定、采样顺序调整和离散历史表示，降低长时自回归滚动中的观测偏差。
  • Model-agnostic finetuning recipe: paper reports that existing video diffusion backbones can be finetuned with FramePack rather than retrained from scratch.
    模型无关微调方案：论文指出现有视频扩散骨干可直接引入 FramePack 微调，而非从零重训。

Method Pipeline

Historical frames → frame-wise importance scoring → packed context construction (variable per frame) → next-frame prediction diffusion model → anti-drift rollout controls → long-horizon video generation
Core intuition: instead of giving every past frame equal context length, FramePack spends more context tokens on high-utility frames and compresses low-utility frames, then stabilizes generation with explicit anti-drift rollout rules.
核心直觉：不是给每个历史帧平均上下文，而是把更多上下文 token 分配给高价值帧、压缩低价值帧，再用显式防漂移策略稳定滚动生成。

The paper reports ablations validating these anti-drift components in both single-direction streaming and bi-directional generation settings.

  • Long-sequence robustness recipe: directly reusable when your pipeline evolves toward long-horizon video generation or iterative simulation loops.
    长序列稳健性方案：当你的系统走向长时视频生成或迭代模拟时，这套策略可直接迁移。
  • Engineering leverage: context packing is a compute/memory optimization pattern, not just a model trick, so it can influence system design choices early.
    工程杠杆价值：context packing 属于算力/内存优化范式，不只是模型技巧，可提前影响系统架构设计。

Limitations / Open Questions

  • Schedule sensitivity: effectiveness can depend on how importance metrics are chosen and tuned per data domain.
    策略敏感性：效果可能依赖重要性度量及其在不同数据域中的调参方式。
  • Compatibility cost: retrofitting existing codebases with packing logic and anti-drift rollout controls may increase implementation complexity.
    兼容成本：在现有代码中加入 packing 和防漂移滚动控制会增加实现复杂度。
  • Quality-speed trade-off remains: packing helps context efficiency, but end-to-end latency still depends on backbone size and sampling budget.
    质量-速度权衡仍在：packing 提升上下文效率，但整体时延仍受骨干规模与采样预算影响。

TL;DR

FramePack is a systems-level upgrade for next-frame video diffusion: it reallocates limited context tokens by frame importance (time/similarity/hybrid), then suppresses long-horizon drift with endpoint anchoring + sampling-order adjustment + discrete history design. The practical takeaway is not only better long-context generation behavior, but also a reusable compute-aware design pattern for long video pipelines.
