Learnable SMPLify: A Neural Solution for Optimization-Free Human Pose Inverse Kinematics

Yuchen Yang, Linfeng Dong, Wei Wang, Zhihang Zhong, Xiao Sun
Skeleton-to-SMPLX SMPLX Inverse Kinematics Optimization-Free arXiv 2025
arXiv PDF Code
One-sentence problem: SMPLify-style iterative inverse kinematics is robust but too slow - can we directly regress SMPL parameter updates from joints in one forward pass while keeping strong generalization?
一句话问题：SMPLify 迭代式逆运动学鲁棒但计算慢——能否在保持泛化能力的同时，用单次前向从关节直接回归 SMPL 参数更新？

Key Contributions

  • Optimization-free neural IK: replaces iterative SMPLify fitting with single-pass residual regression from initialization to target pose parameters.
    无优化神经 IK：用单次残差回归替代 SMPLify 的多轮迭代拟合，从初始化参数直接更新到目标参数。
  • Temporal pair sampling: constructs initialization-target training pairs from adjacent frames to provide realistic transition difficulty.
    时序配对采样：从相邻视频帧构建初始化-目标训练对，形成更真实、可学习的过渡难度。
  • Human-centric normalization: normalizes joint coordinates into a body-centered frame to reduce global pose variance and improve generalization.
    人体中心归一化：将关节坐标映射到人体中心坐标系，减小全局位姿变化带来的解空间复杂度。
  • Practical speedup: paper reports nearly 200x runtime improvement over classical SMPLify while maintaining strong performance on unseen data.
    实用加速：论文报告相对经典 SMPLify 约 200x 提速，同时在未见数据上保持较强表现。

Method Sketch

Initial SMPL params + target joints → human-centric normalized joints → GCN feature extractor → residual SMPL parameter regressor → final pose in one pass

Relation to Existing Tags

  • Skeleton-to-SMPLX track: like HybrIK-X, this work treats pose recovery as IK over parametric human models; the focus is neuralizing iterative optimization.
    Skeleton-to-SMPLX 路线：与 HybrIK-X 类似，都把姿态恢复看作参数化人体模型上的 IK 问题；区别在于该工作强调把迭代优化神经化。
  • Pipeline utility: can serve as a model-agnostic post-processing module to refine outputs from image-based estimators.
    管线价值：可作为模型无关的后处理模块，用于细化图像回归器的输出。

TL;DR

Learnable SMPLify turns SMPLify-style IK into a one-shot neural residual regression problem using temporal pair construction and human-centric normalization. It is a practical baseline in the Skeleton-to-SMPLX line: much faster inference while retaining strong cross-dataset generalization.
