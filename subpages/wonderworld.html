WonderWorld: Interactive 3D Scene Generation from a Single Image

Hong-Xing Yu, Haoyi Duan, Charles Herrmann, William T. Freeman, Jiajun Wu
Stanford University · Google DeepMind

arXiv PDF Project Page
One-sentence problem: Given a single RGB image, can we interactively generate a geometrically consistent and navigable 3D scene at low latency, without requiring multi-view captures or long optimization?
一句话问题：仅给定一张 RGB 图像，能否以低延迟、交互式地生成几何一致、可导航的 3D 场景，而无需多视角采集或漫长优化？
Core idea: WonderWorld decomposes the scene into layered Gaussian surfels and uses a guided depth diffusion model to inpaint unseen regions as the user navigates, achieving fast single-image 3D scene creation where each step takes only seconds.
核心思想：WonderWorld 将场景分解为分层 Gaussian surfels，并利用引导式深度扩散模型在用户导航时对未见区域进行 inpaint，实现快速单图 3D 场景创建，每步仅需几秒。

Key Contributions

  • Layered Gaussian surfels representation: Scenes are represented as layered 2D Gaussian surfels rather than a single point cloud or NeRF volume, enabling efficient differentiable rendering and clean layer-wise compositing as new content is added.
    分层 Gaussian surfels 表示：场景以分层 2D Gaussian surfels 表示，而非单一点云或 NeRF 体积，支持高效可微渲染和逐层合成。
  • Guided depth diffusion for consistent inpainting: When the camera moves to reveal unseen areas, a depth diffusion model conditioned on the known geometry generates geometrically plausible depth for the new regions, avoiding depth discontinuities or floating artifacts.
    引导式深度扩散实现一致 inpainting：摄像机移动暴露未见区域时，以已知几何为条件的深度扩散模型生成新区域的几何合理深度，避免深度断层或悬浮 artifact。
  • Low-latency interactive loop: Unlike prior scene generation approaches that require hundreds of iterations of optimization, WonderWorld generates each new scene layer in seconds, enabling a responsive user-driven authoring workflow.
    低延迟交互闭环：与需要数百次迭代优化的早期方法不同，WonderWorld 每层新内容仅需几秒，实现响应式的用户驱动创作流程。
  • User-specified content and layout: Users can interactively specify what objects and scene elements appear and where, with the system filling in 3D geometry and appearance via the diffusion-based inpainting pipeline.
    用户指定内容和布局：用户可交互式指定场景中出现的物体和元素及其位置，系统通过扩散 inpainting 管线填充 3D 几何和外观。
  • Connected scene topology: The layered representation ensures newly inpainted regions connect seamlessly to the existing scene geometry, producing scenes that can be navigated without visible seams or gaps.
    连通的场景拓扑：分层表示确保新 inpaint 的区域与已有场景几何无缝连接，导航时不出现可见接缝或缺口。

Method / Architecture

Single RGB image → Monocular depth estimation → Layer-0 Gaussian surfels → User navigation / content spec → Guided depth diffusion inpainting → New Gaussian surfel layer → Navigable 3D scene

Initialization: A monocular depth model lifts the input image into an initial Gaussian surfel layer. Surfels are 2D Gaussian primitives aligned to local surface normals, enabling fast alpha-compositing renders from novel views.

Guided depth diffusion: When the user moves the camera, the renderer reveals disocclusion holes. A depth diffusion model conditioned on the rendered partial depth generates complete depth for the inpainted RGB regions, ensuring that new geometry is metrically consistent with the existing layers.

Layer compositing: Each inpainting step adds a new Gaussian surfel layer. Layers are composited in depth order. The separation avoids re-optimizing old layers and keeps inference fast.

Appearance inpainting: A 2D inpainting diffusion model fills RGB content in disoccluded regions, conditioned on the surrounding context. Depth and appearance inpainting are tightly coupled to maintain geometric plausibility.

初始化：单目深度模型将输入图像提升为初始 Gaussian surfel 层。Surfels 是对齐局部法线的 2D Gaussian 基元，支持从新视角快速 alpha 合成渲染。

引导式深度扩散：用户移动摄像机时，渲染器暴露去遮挡空洞。以已渲染部分深度为条件的深度扩散模型为 inpaint RGB 区域生成完整深度，确保新几何与已有层在度量上一致。

分层合成：每次 inpainting 步骤添加新的 Gaussian surfel 层，按深度顺序合成。分层结构避免重新优化旧层，保持推理速度。

外观 inpainting：2D inpainting 扩散模型以周围上下文为条件，填充去遮挡区域的 RGB 内容。深度和外观 inpainting 紧密耦合以维持几何合理性。

Limitations

  • No temporal video input: WonderWorld takes a single static image as input. It does not support continuous egocentric video streams or dynamic object tracking across frames.
    无时序视频输入：WonderWorld 以单张静态图像为输入，不支持连续自我中心视频流或跨帧动态物体跟踪。
  • Bounded navigation range: As the camera moves far from the initial viewpoint, diffusion inpainting quality degrades and accumulated depth errors can cause visual drift.
    导航范围有限：摄像机远离初始视点时，扩散 inpainting 质量下降，累积深度误差可能导致视觉漂移。
  • No metric scale guarantee: The depth estimates are up-to-scale. For AR or robotics applications requiring metric world coordinates, an additional scale calibration step would be needed.
    无度量尺度保证：深度估计是 up-to-scale 的。对于需要度量世界坐标的 AR 或机器人应用，需要额外的尺度标定步骤。
  • Static scenes only: The Gaussian surfel representation does not model dynamic objects. Moving people, hands, or deformable objects are not handled.
    仅限静态场景：Gaussian surfel 表示不对动态物体建模，无法处理运动的人、手或可变形物体。
  • Diffusion inpainting artifacts: Hallucinated content in inpainted regions may be semantically inconsistent with the original image when the disoccluded area is large or structurally ambiguous.
    扩散 inpainting artifact：当去遮挡区域较大或结构模糊时，inpaint 区域的幻化内容可能与原图语义不一致。

TL;DR

WonderWorld (Stanford / Google DeepMind, ECCV 2024, arXiv 2406.09394) generates an interactive navigable 3D scene from a single image in seconds. It uses layered Gaussian surfels as the scene representation and a guided depth diffusion model to inpaint geometrically consistent content as the user moves the camera. The system is orders of magnitude faster than prior scene generation methods and outperforms Text2Room, LucidDreamer, and WonderJourney in user studies. For this paper bank, its value is as a fast scene prior for single-image 3D environment reconstruction; the missing pieces for egocentric AR are metric scale, temporal video input, dynamic object/person handling, and SMPL-X avatar integration.
