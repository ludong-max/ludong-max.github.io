One-sentence problem: Given a single image and a user action (gravity, wind, point force…), can we generate a dynamic 3D scene where objects respond with physically plausible motion across rigid bodies, cloth, liquid, gas, and elastic materials?
一句话问题：给定一张图像和用户动作（重力、风、点力…），能否生成物体对刚体、布料、液体、气体、弹性材料等物理合理地响应的动态 3D 场景？
团队演进线：WonderJourney (CVPR 2024) → WonderWorld (CVPR 2025) → WonderPlay (ICCV 2025 Highlight)
WonderPlay 直接基于 WonderWorld 的 FLAGS 场景表示，在其上叠加物理求解器 + 视频生成闭环，将静态场景升级为可交互动态世界。

Key Contributions

  • Hybrid generative simulator: The core novelty — a physics solver generates coarse 3D dynamics (fast but approximate), which then conditions a video diffusion model to produce fine, realistic motion. The video is back-projected to update the 3D scene, closing the loop.
    混合生成式仿真器：核心创新 — 物理求解器生成粗略 3D 动态（快速但近似），以此为条件驱动视频扩散模型生成精细真实的运动；视频被反投影回 3D 场景形成闭环。
  • Broad material support: Handles rigid bodies, thin strands (hair), gas (steam), elastic objects (mushroom), and liquids (honey) — far beyond the rigid-only or simple elastic limits of prior dynamic 3D generation work.
    广泛材质支持：支持刚体、细线（头发）、气体（蒸汽）、弹性（蘑菇）和液体（蜂蜜）— 远超先前只限刚体或简单弹性的动态 3D 生成工作。
  • Action-conditioned user control: Users apply physical actions (gravity, wind, point forces, fluid injection) to the scene via simple inputs, and WonderPlay generates the resulting 3D dynamics in response.
    动作条件用户控制：用户通过简单输入对场景施加物理动作（重力、风、点力、流体注入），WonderPlay 生成对应的 3D 动态响应。
  • Builds on WonderWorld's FLAGS representation: The static scene from WonderWorld's layered Gaussian surfels serves as the initialization; WonderPlay adds temporal dynamics on top without re-designing the scene representation from scratch.
    基于 WonderWorld 的 FLAGS 表示：以 WonderWorld 分层 Gaussian surfels 静态场景为初始化，在其上叠加时序动态，无需从头重新设计场景表示。
  • Physics-video feedback loop: The generated video provides appearance supervision that guides the physics solver in the next iteration, combining the accuracy of physics-based simulators with the expressivity of diffusion-based video generators.
    物理-视频反馈闭环：生成视频提供外观监督，引导物理求解器下一次迭代，将物理仿真的精确性与扩散视频生成器的表达力结合。

Method / Architecture

Single image + user action → WonderWorld FLAGS scene init → Physics solver: coarse 3D dynamics → Video diffusion: fine realistic motion → Back-project video → update 3D scene → loop for next timestep

Scene initialization: A single RGB image is lifted into a layered Gaussian surfel representation (FLAGS from WonderWorld) using monocular depth estimation, providing the static 3D canvas for dynamics.

Physics solver (coarse): A physics-based simulator (e.g., MPM for granular/fluid/elastic, rigid body solver for objects) computes approximate 3D deformations given the user action. This is fast but lacks appearance realism.

Video diffusion (fine): The coarse physics simulation is rendered and used as a conditioning signal for a video diffusion model, which generates temporally coherent frames with realistic appearance, fine-grained motion details, and material-specific effects.

3D update loop: The video frames are back-projected into 3D to update the Gaussian surfel positions and appearances, closing the loop so the next physics step starts from the updated 3D state. This hybrid loop runs iteratively for multi-step dynamics.

场景初始化：单张 RGB 图像通过单目深度估计提升为 FLAGS 分层 Gaussian surfels 表示，作为动态的静态 3D 画布。

物理求解器（粗略）：物理仿真器（如粒状/流体/弹性用 MPM，物体用刚体求解器）根据用户动作计算近似 3D 形变，速度快但外观真实感不足。

视频扩散（精细）：粗略物理仿真渲染结果作为视频扩散模型的条件信号，生成时序连贯、外观真实、运动细节丰富且材质特异的帧序列。

3D 更新闭环：视频帧被反投影回 3D，更新 Gaussian surfel 的位置和外观，使下一步物理求解从更新后的 3D 状态出发。此混合闭环迭代运行以支持多步动态。

Prior dynamic 3D generation works typically support only rigid body or simple elastic materials. WonderPlay's hybrid simulator is the first to unify all five material types in a single-image 3D scene generation framework.

Limitations

  • Requires material segmentation: The physics solver needs to know which scene region corresponds to which material type. Automatic material segmentation from a single image remains an unsolved problem and is manually specified in current demos.
    需要材质分割：物理求解器需要知道场景各区域对应哪种材质类型，从单张图像自动分割材质仍是未解问题，当前 demo 需手动指定。
  • No metric scale: Inherited from WonderWorld — depth estimates are up-to-scale. Physical simulation magnitudes (force, mass) are therefore also relative, not metric.
    无度量尺度：继承自 WonderWorld — 深度估计是 up-to-scale 的，物理仿真量级（力、质量）因此也是相对而非度量的。
  • Static background only: The Gaussian surfel background is static; only the interacted object/region undergoes dynamics. Full-scene fluid flow or global wind effects are not modeled.
    仅前景动态：Gaussian surfel 背景是静态的，只有被交互的物体/区域产生动态，不支持全场景流体流动或全局风场建模。
  • Video diffusion latency: The video generation step is the bottleneck — real-time physics feedback is not yet achievable; each dynamic step takes several seconds with a diffusion model.
    视频扩散延迟：视频生成步骤是瓶颈 — 目前无法实现实时物理反馈，每步动态仍需扩散模型耗时数秒。

TL;DR

WonderPlay (Stanford + Utah, ICCV 2025 Highlight, arXiv 2505.18151) is the dynamic successor to WonderWorld by the same team. It introduces a hybrid generative simulator: a physics solver generates coarse 3D dynamics, a video diffusion model refines appearance and fine motion, and the video is back-projected to update the 3D scene in a closed loop. The result is action-conditioned dynamic 3D scenes from a single image supporting rigid, elastic, liquid, gas, and strand materials — a capability gap no prior work had closed. The main open problem is metric scale and automatic material segmentation.
