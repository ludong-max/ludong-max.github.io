One-sentence problem: Can a single feed-forward pass predict ready-to-render 3D Gaussians and camera poses simultaneously from any number of uncalibrated images — with no per-scene optimization and no pose annotations?
一句话问题：能否仅凭一次 feed-forward 推理，从任意数量的无标定图像中同时预测可直接渲染的 3D Gaussians 和相机姿态——无需每场景优化，无需任何 pose 标注？
Placement in this bank: AnySplat is not an egocentric body-pose paper. It is included under 3D Scene Reconstruction / Feed-Forward 3DGS because feed-forward uncalibrated 3D reconstruction is a foundational capability for ego AR/VR pipelines: it can generate scene Gaussians from casual Aria or ego-camera captures without COLMAP, serving as a fast scene-prior module upstream of body/hand estimation.
在本库中的定位：AnySplat 不是 egocentric body pose 论文。收录于 3D Scene Reconstruction / Feed-Forward 3DGS，理由是 feed-forward 无标定 3D 重建是 ego AR/VR 管线的基础能力：可直接从 Aria 或普通 ego 相机拍摄中生成场景 Gaussian，无需 COLMAP，作为 body/hand estimation 的上游快速场景 prior 模块。

Key Contributions

  • One-shot uncalibrated scene reconstruction: A single forward pass simultaneously outputs a set of 3D Gaussian primitives (encoding scene geometry and appearance) and the camera intrinsics + extrinsics for every input image — no COLMAP, no SfM, no per-scene optimization required.
    单次推理无标定场景重建：一次 forward pass 同时输出 3D Gaussian 基元（编码场景几何和外观）以及每张输入图像的内参和外参——无需 COLMAP、SfM 或每场景优化。
  • Pseudo-label knowledge distillation (no 3D GT needed): Camera and geometry priors are distilled from the pretrained VGGT model using only raw RGB images, eliminating the need for any 3D SfM or MVS ground truth supervision.
    伪标签知识蒸馏（无需 3D GT）：仅用原始 RGB 图像，从预训练 VGGT 模型中蒸馏相机和几何先验，完全不需要 3D SfM 或 MVS 真值监督。
  • Differentiable voxel-guided Gaussian pruning: A differentiable voxelization module clusters pixel-wise Gaussians into voxels, eliminating 30–70% of redundant primitives while maintaining comparable rendering quality — making dense-view inference practical.
    可微分体素引导 Gaussian 剪枝：一个可微分体素化模块将逐像素 Gaussian 聚类到体素中，消除 30–70% 冗余基元，同时维持渲染质量，让密集视角推理切实可行。
  • Sparse-to-dense scalability: Unlike prior feed-forward methods limited to 2–24 input images, AnySplat generalizes to hundreds of views in one shot, while also handling as few as 3 sparse views.
    稀疏到密集的可扩展性：与以往最多处理 2–24 张输入图像的 feed-forward 方法不同，AnySplat 可一次处理数百张视角，同时也能处理 3 张稀疏视角。
  • Zero-shot generalization: Trained on 9 diverse datasets (indoor/outdoor/object/city), AnySplat matches pose-aware 3DGS baselines and surpasses existing pose-free feed-forward methods in zero-shot evaluations, at an order-of-magnitude lower latency.
    零样本泛化：在 9 个多样数据集上训练后，AnySplat 在零样本评测中达到 pose-aware 3DGS 基线水平，超越现有 pose-free feed-forward 方法，且延迟低一个数量级。

Method / Architecture

N uncalibrated RGB images → Geometry Transformer (DINOv2 patchify + L=24 AA-Transformer + camera tokens) → 3 Decoder Heads (Gaussian FG + Depth FD + Camera FC) → Differentiable Voxelization (prune 30–70% primitives) → 3D Gaussians {μ,σ,r,s,c}G + poses {p}N

Geometry Transformer: Following VGGT, each image is patchified into H×W/p² tokens (p=14, d=1024) using DINOv2. A learnable camera token is prepended to each image. An L=24 Alternating-Attention Transformer applies: (1) frame-level self-attention over each image's tokens, then (2) global cross-image attention over all N×(H_t+5) tokens jointly. This allows implicit multi-view feature matching without explicit correspondence search.

Three decoder heads: (1) Gaussian Head FG: combines DPT depth features with appearance features and a final CNN to regress per-pixel Gaussian params (center μ, opacity σ, quaternion r, scale s, SH color coefficients c). (2) Depth Head FD: outputs per-image depth maps D with per-pixel confidence for geometry supervision. (3) Camera Head FC: four additional self-attention layers + linear projection head predict each image's 9D camera parameter (intrinsics + extrinsics).

Differentiable Voxelization: Clusters the G pixel-wise Gaussian centers {μ_g} into S voxels of size ε=0.002 using a confidence-weighted softmax aggregation. Reduces primitive count from ~4.82M to ~3.45M while improving PSNR from 17.77 to 18.25 (ablation Table 5).

Training (distillation only): Total loss = L_rgb (MSE + perceptual) + λ₂·L_g (geometry consistency) + λ₃·L_p (camera pose distillation from VGGT) + λ₄·L_d (depth distillation from VGGT DPT head). λ₁=0.05, λ₂=0.1, λ₃=10, λ₄=1. No 3D GT annotations used. Trained 15K iterations on 16 A800 GPUs (~2 days), ~886M parameters.

Geometry Transformer：沿用 VGGT 方案，用 DINOv2 将每张图像分块为 H×W/p² 个 token（p=14，d=1024），每张图像前置一个可学习的相机 token。L=24 层 Alternating-Attention Transformer：(1) 逐帧内 self-attention；(2) 跨所有 N 张图像的 global attention。隐式多视角特征匹配，无需显式对应点搜索。

三个解码头：(1) Gaussian Head FG：融合 DPT 深度特征、外观特征和 CNN，回归逐像素 Gaussian 参数（中心 μ、透明度 σ、四元数 r、尺度 s、SH 颜色系数 c）。(2) Depth Head FD：输出逐图像深度图和逐像素置信度，用于几何监督。(3) Camera Head FC：4 层额外 self-attention + 线性投影，预测每张图像的 9D 相机参数（内参+外参）。

可微分体素化：将 G 个逐像素 Gaussian 中心 {μ_g} 聚类到 S 个大小 ε=0.002 的体素，用置信度加权 softmax 聚合。基元数从约 4.82M 降至 3.45M，PSNR 从 17.77 提升到 18.25（消融表 5）。

训练（纯蒸馏）：总损失 = L_rgb（MSE + perceptual）+ λ₂·L_g（几何一致性）+ λ₃·L_p（相机 pose 蒸馏自 VGGT）+ λ₄·L_d（深度蒸馏自 VGGT DPT head）。无任何 3D GT 标注。16 块 A800 GPU 训练约 2 天，~886M 参数。

  • Distillation loss is critical: Removing it collapses PSNR to 7.28 — the model cannot learn stable geometry or camera prediction from rendering loss alone on unposed images. This is the single most important design choice.
    蒸馏损失至关重要：去掉后 PSNR 崩溃至 7.28——仅凭渲染损失无法从无 pose 图像中稳定学习几何和相机。这是最重要的单一设计决策。
  • Geometry consistency loss improves multi-view coherence: Adding L_g reduces AbsRel from 94.7% to 96.3% (improvement) and aligns Gaussian depth with DPT depth estimates, preventing "layered sheet" artifacts that degrade rendering fidelity.
    几何一致性损失改善多视角连贯性：加入 L_g 让 AbsRel 从 94.7% 提升至 96.3%（改善），使 Gaussian 深度与 DPT 深度估计对齐，防止影响渲染保真度的"层状薄片"伪影。
  • Differentiable voxelization improves quality AND reduces primitives: Without it the model uses 4.82M Gaussians to achieve worse quality (PSNR 17.77). The voxelization reduces to 3.45M while boosting PSNR to 18.25 — redundancy elimination forces each primitive to contribute meaningfully.
    可微分体素化同时提升质量和减少基元：不用体素化时，4.82M Gaussian 反而质量更差（PSNR 17.77）。体素化压缩至 3.45M 同时将 PSNR 提升至 18.25——冗余消除迫使每个基元有实质贡献。

Limitations

  • Quality ceiling set by VGGT teacher: Pseudo-label distillation caps geometry and pose accuracy at what VGGT can predict; errors in the teacher propagate into the student's learned priors.
    质量上限受 VGGT 教师制约：伪标签蒸馏使几何和 pose 精度上限取决于 VGGT 的预测质量；教师的误差会传导到学生模型的学习先验中。
  • Static scene only: AnySplat models a single static scene from a set of views. Dynamic objects (people, hands, articulated bodies) are treated as static content and cause blur or artifact Gaussians when present.
    仅限静态场景：AnySplat 对一组视角的单个静态场景建模。动态物体（人、手、关节体）被当作静态内容处理，出现时会产生模糊或伪影 Gaussian。
  • No semantic output: The model outputs Gaussians and camera poses — no per-object identity, no segmentation, no semantic labeling. Downstream ego applications needing object tracking or body segmentation require additional modules.
    无语义输出：模型只输出 Gaussian 和相机 pose，无逐物体 id、分割或语义标签。需要物体跟踪或人体分割的下游 ego 应用需要额外模块。
  • Not temporally consistent across video: AnySplat processes a bag of images, not a video stream. For egocentric video, frames must be batched explicitly and temporal consistency across batches is not guaranteed.
    视频时序不一致：AnySplat 处理一组无序图像，不是视频流。对于自我中心视频，帧需要显式分批，批次间时序一致性无保证。
  • Post-optimization still needed for highest quality dense-view scenarios: While feed-forward inference is fast (seconds), reaching 3DGS-level quality at 200+ views requires 1K–3K post-optimization steps (2–7 min), reducing the real-time advantage.
    高质量密集视角仍需后优化：尽管 feed-forward 推理很快（秒级），在 200+ 视角时达到 3DGS 级质量仍需 1K–3K 步后优化（2–7 分钟），削弱了实时优势。

TL;DR

AnySplat (USTC / Shanghai AI Lab / CUHK, SIGGRAPH Asia 2025) is a feed-forward transformer that takes any number of uncalibrated images and outputs — in a single pass — a set of 3D Gaussian primitives encoding scene geometry and appearance, plus the camera intrinsics and extrinsics for each input image. Key innovations: (1) pseudo-label distillation from VGGT eliminates the need for any 3D ground-truth supervision; (2) differentiable voxelization prunes 30–70% of redundant Gaussians while improving quality; (3) a geometry consistency loss prevents multi-view depth artifacts. In zero-shot benchmarks it matches 3DGS rendering quality on dense-view scenes at >100× lower latency (33s vs 11min on 200 views) and slightly outperforms VGGT on camera pose AUC. For this egocentric paper bank, AnySplat is most relevant as a fast background scene reconstruction module that could eliminate the COLMAP preprocessing step in ego AR pipelines, leaving the open problem of dynamically compositing the SMPL-X human avatar into the Gaussian scene.
